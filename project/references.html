Project References & Image Citations

This page serves as the official citation log for the TRUB (TransitHub) course website assignment.

Sources & Inspirations

  • Design Workflow Concept: Structure modeled conceptually after the public Base44 application prototype workspace layout (trub-travel-flow.base44.app).
  • UI Layout Assets: Vector graphic icons, satellite telemetry badges, and tracking glyph markers sourced from native standard Unicode character system displays.
  • Typography Architecture: Default web-safe typography fallbacks utilized based on core local operating system environments (Cambria, Georgia, Calibri).
  • Project Parameters: Built to satisfy the curriculum objectives outlined in WDD 131: Dynamic Web Fundamentals at Brigham Young University-Idaho.
